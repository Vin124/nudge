A notch for Claude Code

Still doom-scrolling?
Nudge will tap you.

A tiny notch on the edge of your screen that watches every Claude Code session, and tells you the moment one is done or needs you.

Get Nudge View on GitHub

Free and open source · Windows and macOS

~/api-refactor — claude

Three sessions, one glance.

Everything you'd glance at the terminal for.
Without the glancing.

One ring per session

White while it works, green when it's done, orange when it needs you. Each ring fills as that session's context window does.

Usage at a glance

Your 5-hour and weekly limits, straight from Claude Code's own statusline. No guessing when you'll hit the wall.

A fox on your shoulder

When a session wraps up, a little pixel fox peeks out from behind the notch. Click it and you're back in that terminal.

Quiet to loud

Pick a level, or tune glow, sound, voice and the fox for each kind of alert. Do Not Disturb when you're in the zone.

Two commands.
Then forget it's there.

  1. 1

    Add the marketplace

    Inside any Claude Code session:

    /plugin marketplace add Vin124/nudge
  2. 2

    Install the plugin

    /plugin install nudge@nudge
  3. 3

    Start a new session

    Nudge downloads the app for your platform, verifies its checksum, and the notch appears. That's it.

Stays on your machine.

Claude Code reports session state to Nudge over 127.0.0.1 only. Nudge never reads your Claude login unless you switch on live usage, and even then it only talks to api.anthropic.com. Your existing statusline keeps working, untouched.

Made with care for people who'd rather not stare at a terminal.
